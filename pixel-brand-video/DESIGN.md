# Design spec — Arzbar Pixel Stage

Pixel UI frames the work as playable stages: diagnose the bottleneck, connect useful modules, run the four-step Solve Mode, then invite the viewer to bring a real problem.

Use the exact palette in frame.md. Chinese uses Noto Sans TC; Press Start 2P is limited to short English HUD labels and numerals. Keep square corners, navy outlines and hard shadows, pale blue grid texture, orange and blue accents, and the source page's own mascot sprite.

Four 7.5-second scenes follow Stage 01, Stage 02, Stage 03, then the final CTA. Keep copy readable and accurate: AI is one module among options. Use one paused deterministic GSAP timeline per composition and the orange 16×9 pixel-grid wipe. No invented metrics.
